# Лабораторная работа №2 — 2D-игра на Godot

## Технологии
Godot 4 (C#), .NET. Исходники находятся в `Scripts/`, игровые сцены — в `Scenes/`.

## Запуск
1. Откройте папку проекта (с файлом `project.godot`) в Godot с поддержкой C#/.NET.
2. Убедитесь, что установлен совместимый .NET SDK.
3. Дождитесь импорта ресурсов, соберите C# проект и запустите основную сцену кнопкой **F6/F5** (для всего проекта — **F5**).

## Структура и классы
- `Scripts/player.cs` — управление игроком, прыжок, стрельба, получение урона и завершение игры.
- `Scripts/bullet.cs` — снаряд игрока.
- `Scripts/EnemyBullet.cs` — снаряд противника; при контакте с игроком вызывает `TakeDamage()`.
- `Scripts/Dragon.cs` — летающий противник, движется влево и периодически выпускает снаряды.
- `Scripts/Field.cs` — создание врагов, платформ и препятствий по таймерам.
- `Scripts/Classes/MovingObject.cs` — базовое движение и логика появления.
- `Scripts/Classes/Enemy.cs` — здоровье и уничтожение противников.
- `Scripts/Classes/DamagingObject.cs` — общий базовый класс опасных объектов.
- `Scripts/Classes/Obstacle.cs` — препятствия; `Platform.cs` — платформы.
- `Scripts/Bat.cs`, `Zombie.cs`, `Warg.cs`, `Rock.cs`, `Saw.cs`, `Spikes.cs` — конкретные виды объектов.

## Механика дракона
В `Dragon.cs` параметры `HorizontalSpeed`, `BulletSpeed` и `ShootInterval` доступны в инспекторе. `Move()` уменьшает таймер и вызывает `Shoot()`. Сцена вражеской пули загружается из `res://Scenes/enemy bullet.tscn`.

`EnemyBullet` отслеживает физические столкновения и контакт через `Area2D`, вызывает `player.TakeDamage()` и удаляет себя. `player.TakeDamage()` вызывает `Die()`, а `Die()` завершает запуск игры.

## Управление
Действия проекта определены в **Project → Project Settings → Input Map**: `left`, `right`, `jump`, `shoot`.
